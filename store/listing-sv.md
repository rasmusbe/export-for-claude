# Chrome Web Store listing (Swedish)

## Name

Export for Claude

## Summary (max 132 characters)

Spara claude.ai-konversationer som Markdown, JSON eller PDF och ladda ner filerna som zip. Lokalt, utan konto och spårning.

## Description

Export for Claude sparar claude.ai-konversationen du har öppen med ett klick.

• Markdown: hela konversationen med rubrik per tur, tidsstämplar, kodblock, tabeller, artefakter och källorna Claude använde. Verktygsanrop sammanfattas som en kort lista med steg.
• JSON: samma innehåll, strukturerat, för egna verktyg och skript.
• PDF: en ren och utskriftsvänlig sida med bilder, som sparas via webbläsarens "Spara som PDF".
• Filer: ladda ner alla filer i konversationen som zip, med originalnamn och datum: bilder och dokument du laddat upp och filer Claude skapat åt dig.

Fungerar med vanliga chattar, inkognitochattar, delade chattar och Cowork- och Claude Code-sessioner på claude.ai. Har en konversation redigerats eller körts om följer exporten den gren du tittar på.

Integritet först
• Allt körs i din webbläsare. Dina konversationer går aldrig via någon annan server än claude.ai.
• Inget konto, ingen analys, inga annonser och ingen spårning.
• Öppen källkod under MIT-licensen: https://github.com/rasmusbe/export-for-claude

Gränssnittet finns på svenska och engelska.

Export for Claude är ett fristående projekt och har ingen koppling till Anthropic. Claude är ett varumärke som tillhör Anthropic. Extensionen använder claude.ai:s webbgränssnitt, så en ändring på claude.ai kan ibland göra att den slutar fungera tills en uppdatering släpps.
