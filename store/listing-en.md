# Chrome Web Store listing (English)

## Name

Export for Claude

## Summary (max 132 characters)

Save claude.ai conversations as Markdown, JSON or PDF and download their files as a zip. Runs locally, no account, no tracking.

## Description

Export for Claude saves the claude.ai conversation you have open, in one click.

• Markdown: the whole conversation with headings per turn, timestamps, code blocks, tables, artifacts and the sources Claude used. Tool use is summarised as a short list of steps.
• JSON: the same content, structured, for your own tools and scripts.
• PDF: a clean, print-friendly page with images, saved through your browser's "Save as PDF".
• Files: download every file in the conversation as a zip, with original names and dates: images and documents you uploaded and files Claude created for you.

Works with regular chats, incognito chats, shared chats and Cowork / Claude Code sessions on claude.ai. It follows the branch you are looking at when a conversation has edits or retries.

Private by design
• Runs entirely in your browser. Your conversations never pass through any server other than claude.ai.
• No account, no analytics, no ads, no tracking.
• Open source under the MIT license: https://github.com/rasmusbe/export-for-claude

The interface is available in English and Swedish.

Export for Claude is an independent project and is not affiliated with or endorsed by Anthropic. Claude is a trademark of Anthropic. The extension uses claude.ai's web interface, so a change on claude.ai can occasionally break it until an update is released.
